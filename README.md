# Task Manager

Учебный проект на Angular — менеджер задач, который поможет организовать повседневные дела и следить за их выполнением.

## Идея и планируемые возможности

Основная сущность приложения — задача. Для каждой задачи планируется поддержать:

- название и описание;
- статус: новая, в работе или выполнена;
- приоритет;
- срок выполнения.

Также в планах:

- создание, редактирование и удаление задач;
- поиск задач по названию;
- фильтрация по статусу, приоритету и сроку;
- отдельный список задач на сегодня;
- сохранение задач между посещениями приложения.

## Технологии

- Angular 22
- TypeScript
- SCSS

## Домашнее задание №3

- Страницы «Главная», «Задачи» и «Создать» переключаются условным отображением `@switch`, без Angular Router.
- Вкладка текущей страницы выделяется через Class Binding и отключается через Property Binding.
- На странице задач показан демонстрационный массив с `@for`, стабильным `track task.id` и `@empty`.
- Форма создания демонстрирует `[(ngModel)]` и локальное состояние компонента. Задачи не передаются между страницами и не сохраняются после переключения страницы или перезагрузки.

## Домашнее задание №4: реактивные сигналы

- Список задач хранится в `signal()`. Отображение обновляется реактивно, список рендерится через `@for` с `track task.id`.
- Переключение выполнения обновляет новый массив через `update()` без мутации исходного массива или задачи.
- Счётчик задач, счётчик выполненных задач и отфильтрованный список вычисляются через `computed()`.
- Флаг `showCompletedOnly` хранится в `signal()` и переключает фильтр выполненных задач.
- `effect()` логирует изменения списка задач в консоль.

## Запуск проекта

Установите зависимости и запустите сервер разработки:

```bash
npm install
npm start
```

Откройте `http://localhost:4200/`. При изменении файлов приложение перезагрузится автоматически.

Сборка проекта:

```bash
npm run build
```

Запуск тестов:

```bash
npm test
```
